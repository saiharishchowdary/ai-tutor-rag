# AI Tutor Assistant using RAG[cite: 1]

## Tech Stack[cite: 1]
* Tools and Technologies used: Python, LangChain, FAISS/Qdrant, FastAPI, OpenAI[cite: 1].

## System Features & Implementation[cite: 1]
* Built a Retrieval-Augmented Generation (RAG) system to answer queries from uploaded educational documents[cite: 1].
* Designed document ingestion pipeline with chunking, embeddings, and vector storage[cite: 1].
* Implemented semantic search using FAISS/Qdrant to retrieve context-aware responses[cite: 1].
* Developed a chatbot with conversational memory for multi-turn interactions[cite: 1].
* Integrated FastAPI backend for scalable query handling[cite: 1] and reduced hallucination and improved response accuracy using retrieval-based grounding[cite: 1].
